## Typical operating point

Western reference (Philips ECC83 / RCA 12AX7): Ua = 250 V, Rk = 2 kΩ self-bias (≈ Ug1 = −2 V).
Soviet 6N2P (`6Н2П`) reference: Ua = 250 V, Ug1 = −1.5 V.

## Notes

- Soviet 6N2P (`6Н2П`) has **higher gm (2.25 vs 1.6 mA/V)** and **lower Ri** than Western ECC83, despite same nominal μ — it's similar but not a drop-in replacement for low-noise applications
- 5751 is a μ=70 variant (lower noise, more linear), NOT a direct 12AX7 substitute despite shared pinout
- Cathode resistor 2 kΩ in self-bias circuits yields ≈ −2 V grid bias at Ia = 1.2 mA
- PDFs are image-only scans — text not extractable, this extract compiled from rudatasheet.ru tabular data + standard tube reference values
