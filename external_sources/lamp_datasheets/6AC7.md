## Typical operating point

Western reference (RCA/GE 6AC7): Ua = 300 V, Ug2 = 150 V, Rk = 160 Ω (≈ Ug1 = −2 V).
Soviet 6Zh4 (`6Ж4`) reference: same conditions.

| Parameter | RCA 6AC7 | Soviet 6Zh4 (`6Ж4`) | Unit |
|---|---|---|---|
| Ia | 10.0 | 10.25 ± 2.25 | mA |
| Ig2 | 2.5 | 2.2 ± 1.0 | mA |
| S (gm) | 9.0 | 9 ± 2 | mA/V |
| Ri (rp) | ≈ 1000 | 800 | kΩ |
| μ (g1→g2) | 9000 (Sa/Sd) | not specified | — |
| C_in (ccg1) | 11 | 8.5 ± 1.5 | pF |
| C_out (ccp) | 5 | 4.75 ± 1.25 | pF |
| C_gp (cpg1) | 0.015 | ≤ 0.015 | pF |

## Pinout (octal, bottom view)

| Pin | Function |
|---|---|
| 1 | Metal shell (ground) |
| 2 | Heater H |
| 3 | Anode (Pa) |
| 4 | Screen grid (g2) |
| 5 | Control grid (g1) |
| 6 | NC |
| 7 | Heater H |
| 8 | Cathode (K) + suppressor (g3) |
| top cap | none — single-ended construction |

Family: same construction style as 6SJ7 / 6SK7 / 6SH7 / 6SA7 (single-ended octal sharp/remote-cutoff pentodes). NOT like older 6J7 / 6K7 / 6L7 which have top cap.

## Notes

- Sharp-cutoff design — gain compresses quickly above linear region. NOT a remote-cutoff (variable-μ) tube like 6SK7
- Very low Cgp (0.015 pF) thanks to internal shielding — was specifically designed as a single-ended successor to 6J7
- "6AC7 = 6Zh4 (`6Ж4`)" is parametric/functional, not historical: 6Zh4 was Soviet-designed in late 1940s independently following the same single-ended construction; pinout matches 6AC7
- "1852" predates the RMA "6AC7" designation (1939)
- Configs use **RCA conservative values** (Pa=3.0W, Pg2=0.4W) — Soviet datasheet allows slightly more (3.3/0.45)
- PDFs are image-only scans — this extract compiled from Soviet datasheets (rudatasheet.ru tabular form) + standard RCA tube manual reference values
