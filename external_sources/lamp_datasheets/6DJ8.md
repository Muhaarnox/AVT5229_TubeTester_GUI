## Pinout (noval 9-pin, bottom view)

Different from 12AX7 family — separate cathode pins for each section, no shared centre tap.

| Pin | Function |
|---|---|
| 1 | Grid G2 |
| 2 | Cathode K2 |
| 3 | Anode A2 |
| 4 | Heater H |
| 5 | Heater H |
| 6 | Anode A1 |
| 7 | Cathode K1 |
| 8 | Grid G1 |
| 9 | Internal shield |
| top cap | none |

## Equivalents

- Premium: `E88CC` (long-life, low microphonic, gold pins), `6922` (industrial-graded ECC88), `7308` (premium with selected sections)
- Heater variant: `PCC88` (9 V / 300 mA heater for series-string TV use)
- No direct Soviet equivalent — `6N1P` / `6Н1П` has similar μ=35 but different pinout (it's structured like 12AX7 family). `6N23P` / `6Н23П` is closer in spec and pinout to 6DJ8

## Notes

- **Frame-grid** construction → very high gm (12.5 mA/V) and low noise; popular in audio cascodes and phono preamps
- Low cathode-heater isolation (50 V max!) — must use elevated heater supply or isolation transformer when cathode sits high
- ECC88's pinout is **not interchangeable** with 12AX7/12AU7/12AT7 — different pin assignments despite same noval base
- Mullard PDF is image-only scan; this extract draws on standard Philips/Mullard 1958 datasheet reference values
