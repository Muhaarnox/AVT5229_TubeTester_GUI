## Pinout (noval 9-pin, bottom view)

| Pin | Function |
|---|---|
| 1 | Grid G2 |
| 2 | Plate A2 |
| 3 | Cathode K2 |
| 4 | Heater H |
| 5 | Heater H |
| 6 | Plate A1 |
| 7 | Grid G1 |
| 8 | Cathode K1 |
| 9 | Internal shield |
| top cap | none |

Same pinout as 6DJ8 / ECC88 family (separate cathodes, no centre-tap).

## Equivalents

- US: `2C51` (original 1947), `5670` (industrial, very common in computer / radar gear), `396A` (premium, Western Electric), `6385`
- Soviet: `6N3P-E` / `6Н3П-Е` (long-life variant), `6N3P-EV` / `6Н3П-ЕВ` (mil-spec long-life)
- **Different from** 6DJ8 / ECC88: similar gm range but different μ (38 vs 33) and different power ratings

## Notes

- 6N3P (`6Н3П`) / 5670 was extensively used in **computer logic** (mainframe registers, vacuum-tube electronics 1950s-60s) and **radar pulse circuits** — millions produced. Often "new old stock" abundant
- Western Electric 396A is a premium pin-compatible version with extended life — sometimes found in audiophile circles
- High gm + compact form makes it useful as low-noise audio input or cascode CCS
- All PDFs are image-only scans
