# 6N3P — parameters (rudatasheet.ru extract)

Source: <https://rudatasheet.ru/tubes/6n3p/>
Fetched: 2026-05-13

## Description

Dual triode for voltage amplification and high-frequency oscillator service.
Miniature 9-pin base, 22.5 mm diameter.

## Typical operating point

Conditions: Uh=6.3 V, Ua=150 V (typical), Ug1=−2 V

| Parameter | Value | Unit |
|---|---|---|
| Ih (heater current) | 350 | mA |
| S (transconductance) | 4.8…6.0 | mA/V |
| μ (amplification factor) | ~35 | — |

## Maximum ratings

| Parameter | Value | Unit |
|---|---|---|
| Uh (heater voltage range) | 5.7…6.9 | V |
| Ua_max | 300 | V |
| Operating temperature | −60…+85 | °C |

## Equivalents

- Western: `2C51`, `5670`, `396A`, **`6CC42`**

## Notes

- Low-noise audio preamp; suitable for high-frequency applications
- `6CC42` — Telefunken/Philips industrial designation, occasionally seen
