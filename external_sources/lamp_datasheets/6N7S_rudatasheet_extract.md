# 6N7S — parameters (rudatasheet.ru extract)

Source: <https://rudatasheet.ru/tubes/6n7s/>
Fetched: 2026-05-13

## Description

Dual triode for low-frequency voltage amplification. Octal base, glass envelope, 50 g.

## Typical operating point

Conditions: Uh=6.3 V, Ua=300 V, Ug1=−6 V

| Parameter | Value | Unit |
|---|---|---|
| Ih | 810 ± 50 | mA |
| Ia (parallel-connected triodes) | 6.75 ± 2.25 | mA |
| μ | 35 | — |
| Pout (class B PP, Ug=35V signal, Ra=2.5kΩ) | ≥ 4.2 | W |

## Maximum ratings

| Parameter | Value | Unit |
|---|---|---|
| Uh (heater voltage range) | 5.7…6.9 | V |
| Ua_max | 300 | V |
| Pa_max per triode | 5.5 | W |
| Operating temperature | −60…+70 | °C |
| Service life | ≥ 750 | h |

## Equivalents

- Western: **`6N7G`** (RCA)

## Notes

- **Common-cathode** dual triode for class-B push-pull output
- 4.2W minimum output (per datasheet) at heavy drive — historically used in battery portable radios
- Note: parametric values differ slightly from RCA 6N7 — Russian version slightly lower-current
