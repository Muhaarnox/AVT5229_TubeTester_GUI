# 6P1P — parameters (rudatasheet.ru extract)

Source: <https://rudatasheet.ru/tubes/6p1p/>
Fetched: 2026-05-13

## Description

Pentode for low-frequency output stages. Miniature glass envelope, 22.5 mm diameter.

## Typical operating point

Conditions: Uh=6.3 V, Ua=250 V, Ug2=250 V

| Parameter | Value | Unit |
|---|---|---|
| Ih | 500 ± 50 | mA |
| Ia | 45 ± 13 | mA |
| Pout (Ra=5kΩ) | ≥ 3 | W |
| S (transconductance) | 4.9 ± 1.1 | mA/V |
| Ri (internal resistance) | 42.5 ± 22.5 | kΩ |

## Maximum ratings

| Parameter | Value | Unit |
|---|---|---|
| Ua_max | 250 | V |
| Ug2_max | 250 | V |
| Pa_max | 12 | W |
| Pg2_max | 2.5 | W |
| Ik_max | 70 | mA |
| Operating temperature | −60…+70 | °C |
| Service life | ≥ 2000 | h |

## Equivalents

- Western: **`6AQ5` / `EL90`** (per rudatasheet — this matches what I had in 6P1P.md)

## Notes

- **Confirmed equivalent to 6AQ5/EL90** per rudatasheet directly (despite different physical pinout — noval B9A vs B7G 7-pin miniature)
- Common in Soviet table radios; 1960s "Volna", "Spidola" output stages
- Beam tetrode construction internally
