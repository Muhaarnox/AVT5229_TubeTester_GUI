## Description

Single triode for low-frequency voltage amplification.
Octal base (8-pin), glass envelope.

## Typical operating point

Conditions: Uh = 6.3 V, Ua = 250 V, Ug1 = −8 V

| Parameter | Value | Unit |
|---|---|---|
| Ia (anode current) | 9 ± 3.5 | mA |
| S (transconductance) | 2.3 ± 0.6 | mA/V |
| μ (amplification factor) | 20.5 ± 2.5 | — |

## Maximum ratings

| Parameter | Value | Unit |
|---|---|---|
| Uh (heater voltage range) | 5.7…6.9 | V |
| Ua_max | 330 | V |
| Pa_max | 2.75 | W |
| Ik_max (cathode current) | 200 | mA |
| Operating temperature | −60…+70 | °C |
| Minimum service life | ≥ 2000 | h |

## Equivalents

- Western: `6J5GT`

## Notes

- Standard single-section voltage amplifier triode
- Function-equivalent to one section of 6SN7 / 6N8S (`6Н8С`)
