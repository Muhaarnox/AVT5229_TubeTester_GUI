# 6SC7 — Datasheet Extract

Primary: `6SC7`
Aliases: `6SC7GT`, `VT-220` (military)
Topology: dual triode (high-µ, common-cathode)
Base/Construction: octal 8-pin, metal envelope (some variants glass), no top cap. **Single common cathode** (pin 8) — both triodes share cathode internally

## Pinout (octal, bottom view)

| Pin | Function |
|---|---|
| 1 | Shell (metal envelope) |
| 2 | Heater H |
| 3 | Plate A1 |
| 4 | Grid G1 |
| 5 | Plate A2 |
| 6 | Grid G2 |
| 7 | Heater H |
| 8 | **Cathode (common to both sections)** |
| top cap | none |

**Different from 6SN7 / 6SL7**: only one cathode pin (8), shared between both triodes. Pin 5/6 are A2/G2 (vs 5/6 cathode/plate on 6SN7).

## Equivalents

- Variants: `6SC7GT` (glass), `6SC7Y` (loktal-base equivalent), `VT-220` (military)
- Civilian similar: `6F8G` (loktal-base relative)
- **No direct Soviet equivalent** — common-cathode dual triodes are rare in Soviet line; closest function is single-cathode designs like `6F1P` / `6Ф1П` (different pinout)

## Notes

- **Common-cathode topology** is the defining feature: both sections share pin 8 cathode internally. This makes 6SC7 ideal for **phase-splitter / paraphase / cathodyne** configurations where shared cathode bias is natural
- NOT a drop-in for 6SN7 / 6SL7 — the missing per-section cathode pin breaks any circuit that uses individual cathode biasing
- Was widely used in 1940s-50s audio (especially Western Electric, RCA studio amps) as an input/PI stage
- Lower power per section (0.5 W) than 6SN7 (5 W) or 6SL7 (1 W) — strictly small-signal
- PDF is image-only scan
