## Pinout (octal, bottom view)

Single-ended construction — same family as 6AC7, no top cap.

| Pin | Function |
|---|---|
| 1 | Metal shell (ground) |
| 2 | Heater H |
| 3 | Plate (Pa) |
| 4 | Control grid (g1) |
| 5 | Cathode (K) |
| 6 | Screen grid (g2) |
| 7 | Heater H |
| 8 | Suppressor grid (g3) — typically internally tied to cathode |
| top cap | none |

## Equivalents

- Variants: `6SJ7GT` (glass), `6SJ7Y` (industrial), `5693` (premium RCA red-base, low-microphonic)
- Soviet: **`6Zh8` / `6Ж8`** — direct pin-compatible, very similar parameters
- Not interchangeable with 6AC7: 6SJ7 is medium-gm (1.65), 6AC7 is high-gm (9). Same family, different design point

## Notes

- Workhorse pentode for AF voltage amplification — high μ (1500!) and low input/output capacitance make it valued for high-gain audio preamps
- Very low Cgp (0.005 pF) thanks to internal shielding — same construction principle as 6AC7
- `5693` RCA Red Base is the premium variant — selected for low microphonics, 10000+ hr life
- AVT5229 socket: `D` per `config/lamps.json`
