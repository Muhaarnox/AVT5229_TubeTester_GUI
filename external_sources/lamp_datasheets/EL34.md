## Typical operating point (SE, class A, ULTRA-LINEAR not assumed)

Philips/Mullard reference: Ua = 250 V, Ug2 = 250 V, Ug1 = −13.5 V
JJ EL34 II reference: Ua = 250 V, Ug2 = 265 V, Ug1 = −13.5 V

## Pinout (octal, bottom view)

| Pin | Function |
|---|---|
| 1 | Suppressor grid (g3) — internally connected |
| 2 | Heater H |
| 3 | Anode (Pa) |
| 4 | Screen grid (g2) |
| 5 | Control grid (g1) |
| 6 | (no connection on most variants; sometimes g3) |
| 7 | Heater H |
| 8 | Cathode (K) |
| top cap | none |

Note: EL34 brings g3 out on pin 1 separately from cathode (unlike many beam tetrodes). This allows triode-strapping g2+g3+anode for triode mode.

## Equivalents

- US near-equivalent: **6CA7** — RCA / GE / Sylvania version, often labelled as same tube but historically beam tetrode (KT77-like). Curves match closely but not identical
- **KT77** (Genalex) — beam tetrode, more linear in triode mode, slightly higher Pa_max
- **E34L** (JJ Electronic) — heavy-plate / long-life variant of EL34. Pin-compatible. Slightly higher Pa_max (~30 W), more robust construction, sometimes labelled together with EL34 on combined datasheets
- **KT88** — NOT a direct replacement (different μ, higher power)
- **`6P3S-E` / `6П3С-Е`** (Soviet 6L6 family) — NOT a direct replacement despite some 6CA7 vs 6L6 confusion in literature
- No direct Soviet equivalent — Russian-market new production "EL34" by Svetlana/Reflektor/Tung-Sol uses Western EL34 spec

## Notes

- Mullard 5-20 schematic (1956) is the canonical PP class-AB1 reference design
- Triode-strapping (g2 tied to anode through 100 Ω): μ_triode ≈ 8, Ra ≈ 1.2 kΩ, max Pa ≈ 12 W
- 6CA7 historically referred to American beam-tetrode variant (smooth-plate KT77-like construction). Modern Chinese "EL34/6CA7" reissues are usually true pentodes
- **JJ E34L vs EL34** (per JJ Electronic combined datasheet): same pinout, same nominal gm/μ, but heavier plate and slightly higher dissipation rating (~30 W vs 25 W). Within E34L's spec one can drive somewhat harder PP class-AB stages; under conservative load both behave like EL34
- **JJ "EL34 II"** is JJ's nameplate for their basic EL34 production line (not a different tube — Pa=25 W, gm=11, μ=11, Ri=15 k all identical to classic EL34). Capacitances slightly higher than Mullard (C_a=10 pF vs 8.4 pF, C_a/g1=1.3 pF vs 1.1 pF) reflecting their newer construction geometry. Typical-point Ug2=265 V instead of 250 V in JJ spec — for the same Ia=100 mA they accept slightly higher Ug2 in marketing
- Mullard/Philips PDFs are image-only scans; **JJ EL34 II PDF is text-extractable** (Adobe InDesign source) — use that for parametric citation when needed
- This extract compiled from Philips/Mullard 1956–1971 datasheet reference values + Mullard 5-20 application notes + JJ Electronic EL34 II text + E34L marketing notes
