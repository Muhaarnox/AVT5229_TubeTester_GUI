## Typical operating point

Reference (Philips/Mullard SE class A): Ua = 250 V, Ug2 = 250 V, Ug1 = −7.3 V

| Parameter | Philips/Mullard EL84 | PSVANE EL84 | Unit |
|---|---|---|---|
| Ia | 48 | 48 | mA |
| Ig2 | 5.5 | 5.5 | mA |
| S (gm) | 11.3 | 11.3 | mA/V |
| Ri (rp) | 38 | 40 | kΩ |
| μ_g1-g2 | 19 | 19 | — |
| C_in (ccg1) | 10.8 | 10 | pF |
| C_gp | 0.5 | 0.6 | pF |
| C_out (ccp) | 6.5 | 5.1 | pF |
| Pout (SE class A) | ≈ 5.7 | 5.7 (10% dtot, fixed bias) / 6.0 (Ig1 = 0.3 µA) | W |

PP class AB1 (Mullard 5-10): Ua = 300 V, Ug2 = 270 V, Rg-g = 8 kΩ → ~17 W out per pair.

PSVANE SE class-A block (p.1–2) states the same point with the cathode resistor
given explicitly: Ua = Ug2 = 250 V, **Rk = 135 Ω** (auto bias — consistent with
Ik = 48 + 5.5 = 53.5 mA → 7.2 V ≈ the quoted Ug1 = −7.3 V), Ra = 5.2 kΩ,
Ug1eff(50 mW) = 0.3 V, Ug1eff(N) = 4.3 V. No push-pull table, no per-tube
matching/selection point is published.

## Equivalents

- US: `6BQ5` (direct), `7189` / `7189A` (premium, slightly higher Ua), `7320`
- Soviet: **`6П14П` (6P14P)** — direct pin-compatible equivalent. **`6П18П` (6P18P)** — newer variant with longer life
- UK military: `CV2975`
- Modern reissues: JJ, Sovtek (Reflektor), Mullard reissue (NEW SENSOR / xpo), Genalex Gold Lion (E84L variant)

## Notes

- **Mullard 5-10** PP class-AB1 (Williamson topology, 1957) — classic reference design using two EL84 in push-pull
- Used heavily in Vox AC15, AC30, Marshall 18W, etc. — guitar amp icon
- Triode-strapped: μ ≈ 19, Ri ≈ 1.7 kΩ, Pout ≈ 1.7 W (SE) — niche audiophile use
- AVT5229 socket: `B` per `config/lamps.json`
- Philips/Mullard/JJ PDFs are image-only scans; the PSVANE PDF is text-extractable
- PSVANE publishes no matching/selection operating point of its own — the ±5…15 %
  Ip/Gm matching quoted by resellers (Viva Tubes, thetubestore, TAD) is their own
  bench procedure on Maxi-Matcher-class testers, not a factory-published condition.
  For a bench comparison against the sheet, use Ua = Ug2 = 250 V, Ug1 = −7.3 V
  (Ia = 48 mA, Ig2 = 5.5 mA) — the same point as every classic EL84 sheet
